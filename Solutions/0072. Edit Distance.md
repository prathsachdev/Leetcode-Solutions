# [0072. Edit Distance](https://leetcode.com/problems/edit-distance)

<!-- description:start -->

<p>Given two strings <code>word1</code> and <code>word2</code>, return <em>the minimum number of operations required to convert <code>word1</code> to <code>word2</code></em>.</p>

<p>You have the following three operations permitted on a word:</p>

<ul>
    <li>Insert a character</li>
    <li>Delete a character</li>
    <li>Replace a character</li>
</ul>
<p>&nbsp;</p>

<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> word1 = &quot;horse&quot;, word2 = &quot;ros&quot;
<strong>Output:</strong> 3
<strong>Explanation:</strong> 
horse -&gt; rorse (replace &#39;h&#39; with &#39;r&#39;)
rorse -&gt; rose (remove &#39;r&#39;)
rose -&gt; ros (remove &#39;e&#39;)
</pre>

<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> word1 = &quot;intention&quot;, word2 = &quot;execution&quot;
<strong>Output:</strong> 5
<strong>Explanation:</strong> 
intention -&gt; inention (remove &#39;t&#39;)
inention -&gt; enention (replace &#39;i&#39; with &#39;e&#39;)
enention -&gt; exention (replace &#39;n&#39; with &#39;x&#39;)
exention -&gt; exection (replace &#39;n&#39; with &#39;c&#39;)
exection -&gt; execution (insert &#39;u&#39;)
</pre>
<p>&nbsp;</p>

<p><strong>Constraints:</strong></p>
<ul>
    <li><code>0 &lt;= word1.length, word2.length &lt;= 500</code></li>
    <li><code>word1</code> and <code>word2</code> consist of lowercase English letters.</li>
</ul>
<p>&nbsp;</p>

### **Approach 1: Memoization**

<!-- tabs:start -->

```java
class Solution {
    public int[][] dp;
    
    public int solve(int i, int j, String word1, String word2) {
        // Base Case
        if (i < 0) {
            return (j + 1);
        }
        
        if (j < 0) {
            return (i + 1);
        }
        
        // Caching
        if (dp[i][j] != 0) {
            return dp[i][j];
        }
        
        // Recurrence
        if (word1.charAt(i) == word2.charAt(j)) {
            dp[i][j] = solve(i - 1, j - 1, word1, word2);
            return dp[i][j];
        }
        
        int insert = 1 + solve(i, j - 1, word1, word2);
        int delete = 1 + solve(i - 1, j, word1, word2);
        int replace = 1 + solve(i - 1, j - 1, word1, word2);
        
        dp[i][j] = Math.min(insert, Math.min(delete, replace));
        return dp[i][j];
    }
    
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        
        dp = new int[m][n];
        
        return solve(m - 1, n - 1, word1, word2);
    }
}
```

### **Approach 2: Tabulation**

We define $dp[i][j]$ as the minimum number of operations to convert $word1$ of length $i$ to $word2$ of length $j$. $dp[i][0] = i$, $dp[0][j] = j$, $i \in [1, m], j \in [0, n]$.

We consider $dp[i][j]$:

- If $word1[i - 1] = word2[j - 1]$, then we only need to consider the minimum number of operations to convert $word1$ of length $i - 1$ to $word2$ of length $j - 1$, so $dp[i][j] = dp[i - 1][j - 1]$;
- Otherwise, we can consider insert, delete, and replace operations, then $dp[i][j] = \min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1$.

Finally, we can get the state transition equation:

$$
dp[i][j] = \begin{cases}
i, & \textit{if } j = 0 \\
j, & \textit{if } i = 0 \\
dp[i - 1][j - 1], & \textit{if } word1[i - 1] = word2[j - 1] \\
\min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1, & \textit{otherwise}
\end{cases}
$$

Finally, we return $dp[m][n]$.

The time complexity is $O(m \times n)$, and the space complexity is $O(m \times n)$. $m$ and $n$ are the lengths of $word1$ and $word2$ respectively.

<p><strong>Time Complexity:</strong> $O(m \times n)$</p>
<p><strong>Space Complexity:</strong> $O(n)$</p>

<!-- tabs:start -->

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        
        int[][] dp = new int[m + 1][n + 1];
        
        // Base Case
        for (int i = 0; i <= m; ++i) {
            dp[i][0] = i;
        }
        
        for (int j = 0; j <= n; ++j) {
            dp[0][j] = j;
        }
        
        // Recurrence
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    int insert = 1 + dp[i][j - 1];
                    int delete = 1 + dp[i - 1][j];
                    int replace = 1 + dp[i - 1][j - 1];
                    
                    dp[i][j] = Math.min(insert, Math.min(delete, replace));
                }
            }
        }
        
        return dp[m][n];
    }
}
```
